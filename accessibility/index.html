Accessibility

Accessibility statement

This statement applies to sma-consulting.co.uk. We want as many people as possible to be able to use this website, and we build it to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA.

What we have done

  • Every page is plain, server-rendered HTML that works without JavaScript.
  • Text meets AA contrast against its background, and the site can be zoomed to 400% without loss of content.
  • All pages can be navigated by keyboard, with a visible focus state and a skip-to-content link.
  • Images carry text alternatives, and motion is reduced for visitors who request it.

Reporting a problem

If you find something on this site you cannot use, or need content in a different format, email sma@pantheos.co.uk. We will reply within five working days.

This statement was prepared in September 2026.
